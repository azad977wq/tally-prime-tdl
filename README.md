# Tally Prime 6.0 - Bags Column Configuration

এই প্রজেক্টে Tally Prime 6.0-এর জন্য একটি কাস্টম TDL ফাইল রয়েছে যা **Bags (ব্যাগ)** কলাম যোগ করে।

## 📋 বৈশিষ্ট্য

✅ **Purchase (ক্রয়) ভাউচারে Bags কলাম যোগ**
- ক্রয় করা পণ্যের ব্যাগ সংখ্যা ট্র্যাক করুন

✅ **Sales (বিক্রয়) ভাউচারে Bags কলাম যোগ**
- বিক্রয় করা পণ্যের ব্যাগ সংখ্যা রেকর্ড করুন

✅ **Stock Journal ভাউচারে Bags কলাম যোগ**
- স্টক সমন্বয়ে ব্যাগ তথ্য যোগ করুন

✅ **Godown Summary রিপোর্টে Bags প্রদর্শন**
- প্রতিটি গোডাউনে ওপেনিং, ইনওয়ার্ড, আউটওয়ার্ড এবং ক্লোজিং ব্যাগ দেখুন

## 🚀 কিভাবে ব্যবহার করবেন?

### বিস্তারিত নির্দেশনার জন্য দেখুন:
👉 **[INSTALLATION.md](./INSTALLATION.md)** - সম্পূর্ণ ইনস্টলেশন গাইড

## 🔧 TDL এ কি আছে?

### १. **Voucher Master Configuration**
- Purchase মাস্টারে Bags ফিল্ড যোগ
- Sales মাস্টারে Bags ফিল্ড যোগ
- Stock Journal মাস্টারে Bags ফিল্ড যোগ

### २. **Stock Item Configuration**
- Bags Quantity ডেফিনিশন
- Bags ইউনিট কনফিগারেশন

### ३. **Inventory Voucher Lines**
- Purchase লাইনে Bags কলাম
- Sales লাইনে Bags কলাম
- Stock Journal লাইনে Bags কলাম

### ४. **Godown Summary Report**
নতুন রিপোর্ট যা দেখায়:
- **Opening Bags** - খোলার ব্যাগ
- **Inward Bags** - প্রবেশকারী ব্যাগ
- **Outward Bags** - প্রস্থানকারী ব্যাগ
- **Closing Bags** - সমাপনী ব্যাগ
